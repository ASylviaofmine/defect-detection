## 第一部分　Python 语言

### 1. 变量与数据类型
**一句话本质**：变量是"贴了名字的盒子"，类型决定这个盒子能干什么事。

**你用过的类型**

| 类型 | 例子 | 你用过的地方 |
|---|---|---|
| `int` 整数 | `300` | day8 缺陷数量 |
| `float` 小数 | `88.5` | day2 平均分 |

| `list` 列表 | `[1, 2, 3]` | day5 每张图的缺陷数 |

**坑**：`input()` 拿回来的**永远是字符串**，要算数必须先 `int()` 或 `float()` 转。

### 2. 运算符
**一句话本质**：`+ - * /` 是算术；`==` 是"问相等吗"，`=` 是"赋值"（完全不同的两件事）。

**坑**：`=` 和 `==` 混用是最常见的报错来源；`//` 整除、`%` 取余、`**` 乘方。
**🔗 补课**：BV1qW4y1a7fU **p16~p20**

### 3. 字符串与 f-string 格式化 ★重点
**一句话本质**：`f"..."` 里的 `{}` 会被"塞进值"，`:` 后面写"格式要求"。

**你的代码证据**（day2 作业练习.py:13，你一次写了三行试精度）

```python
print(f"平均分: {sum(scores) / len(scores):.1f}")   # 保留 1 位小数
print(f"平均分: {sum(scores) / len(scores):.0f}")   # 保留 0 位
print(f"平均分: {sum(scores) / len(scores):.5f}")   # 保留 5 位
```

**格式说明符速查**

| 写法 | 意思 | 例子 |
|---|---|---|
| `:.1f` | 小数保留 1 位 | `16.7` |
| `:<16` | 左对齐，占 16 格 | 文字列 |
| `:>6` | 右对齐，占 6 格 | 数字列 |
| `:^10` | 居中，占 10 格 | 标题 |
| `:28s` | 字符串占 28 格（左对齐） | day8 你写的 `{t:28s}` |

**字符串方法**（day8 你全用上了）

```python
f.replace(".xml", "")        # 删掉后缀
stem.split("_")              # 按下划线切成列表
"_".join(["pitted","surface"])   # 用下划线拼回去 -> "pitted_surface"
"123".isdigit()              # 判断是不是纯数字 -> True
f.endswith(".xml")           # 判断结尾
```

**坑（两个都很坑）**
1. **中文占 2 格**：`:<18` 是按"字符个数"数的，中文表头会整体右移 2 格（详见 day8 文件里的说明）
2. 宽度是"**至少**"不是"最多"：内容超长不会被截断，只会把格子撑破

**🔗 补课**：BV1qW4y1a7fU **p21~p28**（字符串与格式化）

### 6. 数据容器：列表 list ★

### 10. 函数 def / return

## 第二部分　OpenCV

### 1. 最核心的观念 ★★★
**一句话本质**：**一张灰度图 = 一张数字表格。** 200×200 的图，就是 200 行 × 200 列的数字，每个数字 0~255（0 全黑，255 全白）。

**你的代码证据**（day7 practice(rest2).py，你亲自验证过）

```python
img = cv2.imread(..., cv2.IMREAD_GRAYSCALE)   # 读成灰度
print(img.shape)      # (200, 200)  ← 高 200 行、宽 200 列
print(img.dtype)      # uint8      ← 每个数是 0~255 的整数
print(img[0, 0])      # 114        ← 第 0 行第 0 列的像素值
```

**彩色图和灰度图的区别**

| | shape | 含义 |
|---|---|---|
| 彩色 | `(200, 200, 3)` | 每个像素有 **3 个数**（蓝、绿、红） |
| 灰度 | `(200, 200)` | 每个像素只有 **1 个数**（亮度） |

**记住这条，后面全通**：OpenCV 的所有操作（滤波、边缘检测、形态学）**本质上都是对这堆数字做加减乘除**。

### 2. 读图 / 保存
**一句话本质**：`imread` 读进来 → 处理 → `imwrite` 存出去。

```python
img = cv2.imread("路径.jpg")                       # 读成彩色
gray = cv2.imread("路径.jpg", cv2.IMREAD_GRAYSCALE) # 读成灰度
cv2.imwrite("practice/out/结果.png", gray)          # 存到 out 目录
```

**坑（很重要）**：**路径写错不会报错，只会返回 `None`**，后面所有操作都会崩在莫名其妙的行。所以路径一定要用"检查是否 None"来验证。
另外：**输出去 `out/`，永远不要往原图路径写**（会覆盖素材，你 day7 踩过一次）。

### 3. 颜色空间转换 cvtColor
**一句话本质**：把彩色（3 个数）压成灰度（1 个数）。

```python
gray = cv2.cvtColor(color, cv2.COLOR_BGR2GRAY)
```

**坑**：OpenCV 默认顺序是 **BGR**（蓝绿红）不是 RGB——所以叫 `COLOR_BGR2GRAY`。

### 4. 缩放 resize
```python
small = cv2.resize(img, (100, 100))     # 宽 100、高 100
```

**坑**：`resize` 的参数是 **(宽, 高)**，而 `img.shape` 打印出来是 **(高, 宽)** —— **正好相反**，这是最容易搞混的一处。

### 5. 滤波去噪 ★
**一句话本质**：把每个像素换成"它和邻居的平均值"，用来磨掉噪点。

```python
b5  = cv2.GaussianBlur(img, (5, 5), 0)    # 高斯滤波，核 5×5
b15 = cv2.GaussianBlur(img, (15, 15), 0)  # 核越大 → 越模糊
```

**坑**：核的尺寸**必须是奇数**（3、5、7…），写偶数会直接报错。
**你实际看到的**：k=15 比 k=5 明显更模糊——这就是"参数对结果的影响"最直观的例子。

### 6. 形态学（明天 10/12 学）
**一句话本质**：用一个小模板在图上"涂抹"，让亮的区域变胖/变瘦/断开的连起来。
- **腐蚀 erode**：亮的区域变瘦（去掉小块噪点）
- **膨胀 dilate**：亮的区域变胖（把断开的连上）
- **开运算 open**：先腐蚀再膨胀（去小噪点，形状基本不变）
- **闭运算 close**：先膨胀再腐蚀（补小洞）

### 7. 阈值 threshold（明天 10/12 学）
**一句话本质**：定一条线，比它亮的变纯白、比它暗的变纯黑。`cv2.threshold(...)`

### 8. 边缘检测 ★（明天 10/12 学）
**一句话本质**：**找出"数字突然变化"的地方**——因为物体的边界处，像素值会发生跳变。

```python
edges = cv2.Canny(img, 50, 150)        # 两个参数是"弱边/强边"的门槛
```

**你已经知道的结论**（我实测过真实数据）：裂纹图（crazing）Canny 后白像素 **15149 个（占全图 38%）**，夹杂图（inclusion）只有 **236 个**。同一套参数，一个把整图都标成边缘、一个干干净净——**这就是传统方法搞不定"纹理型缺陷"的证据**，也是你项目"为什么用深度学习"的核心论据。

### 9. 轮廓与画框（明天 10/12 学）
```python
cnts = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
x, y, w, h = cv2.boundingRect(c)                # 求外接矩形
cv2.rectangle(img, (x, y), (x+w, y+h), (0,0,255), 2)   # 在图上画出来
```

**坑**：实测裂纹图能找出 **237 个框**，但真缺陷只有 1 个——"框不准"就是传统方法的死穴。
